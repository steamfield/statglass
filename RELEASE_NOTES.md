# StatGlass 0.13.1

StatGlass is a free, open-source system monitor for Apple Silicon Macs running macOS
26 or later.

This is a small follow-up to 0.13.0.

## Fixes

- On a host card's reconnect panel, a long SSH error now fits on one line, and the
  full text shows on hover or keyboard focus, matching the card's other message lines.
- Updated the `url` crate to 2.5.9, which fixes RUSTSEC-2026-0592.
